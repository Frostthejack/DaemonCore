# Sound Files — Placeholders

These `.ogg` files are **placeholder containers** and should be replaced with real audio files before production use.

## Files

| File | Purpose | Suggested Sound |
|------|---------|-----------------|
| `thinking.ogg` | Pet is thinking/processing | Soft chime or gentle tone |
| `working.ogg` | Pet is working on a task | Subtle click or short beep |
| `done.ogg` | Task completed successfully | Positive confirmation tone |
| `error.ogg` | Error occurred | Low alert tone or buzz |

## Replacement Guidelines

- Format: Ogg Vorbis (`.ogg`)
- Max size: 30KB per file (50KB hard limit)
- Duration: < 1 second recommended
- License: CC0 or your own recordings
- Sources: [freesound.org](https://freesound.org) (CC0 filter), [Audacity](https://www.audacityteam.org/) (generate tones), or any online tone generator

## Current Status

These are minimal valid Ogg container files (silent, ~58 bytes each). They will not produce audible sound. Replace them with real audio for the fallback sound system to work.
